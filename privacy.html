Privacy Policy

Last updated: 26 October 2026

"Vsesvit Studio Helper" (the "Tool") is a private, internal command-line tool used by Pavlo Chornyi to manage his own YouTube channel «А чому Всесвіт такий?». The Tool has a single user — the channel owner. It is not offered to the public, has no sign-up, and collects nothing from third parties.

1. Who we are

Pavlo Chornyi, independent content creator (sole proprietor), Ukraine. Contact: chornyipavlo1987@gmail.com.

2. YouTube API Services

The Tool uses the YouTube Data API v3 (YouTube API Services) to, on the owner's own channel only: upload the owner's own videos; set and update titles, descriptions, tags, video language, category and localizations; set thumbnails; set privacy status and scheduled publish time; create playlists and add the owner's own videos to them; post a comment from the channel under its own videos; and read the owner's own channel and video metadata to verify the above.

By using the YouTube API Services, the Tool is subject to the YouTube Terms of Service and to the Google Privacy Policy.

3. Data we access

The Tool accesses only data belonging to the channel owner, through the owner's own Google Account and the owner's explicit OAuth 2.0 consent: the channel id, title and uploads playlist; metadata of the owner's own videos; and the video and image files the owner selects on their own computer.

The Tool does not access, collect, store or process any other user's or viewer's data, personal data of third parties, comments written by others, YouTube Analytics, revenue data, or audience, demographic or behavioural data.

4. Storage and retention

  • The OAuth refresh/access token is stored only locally, in a file on the owner's personal computer, readable by the owner's operating-system account only.
  • API responses are used in memory to print the result in the terminal. The Tool keeps no database, no analytics store and no server-side copy.
  • Any YouTube API data written to local working notes is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.
  • No data is sold, shared or transferred to any third party, and nothing is transmitted anywhere except to Google and YouTube APIs over HTTPS.

5. Revoking access and deleting data

The owner may revoke the Tool's access at any time at https://myaccount.google.com/permissions. Deleting the local token file ends all access immediately. Because the Tool keeps no server-side storage, revoking access and deleting that file deletes all data the Tool holds. To request deletion of anything related to the Tool, write to chornyipavlo1987@gmail.com.

6. Children

The Tool is used by the channel owner only and is not directed at children.

7. Security

Credentials never leave the owner's computer. All API traffic uses HTTPS. The Tool is not publicly accessible and exposes no network service, login page or endpoint.

8. Changes

Material changes to this policy will be published on this page with a new "Last updated" date.
