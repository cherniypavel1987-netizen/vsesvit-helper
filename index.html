Vsesvit Studio Helper

A private, single-user tool used by Pavlo Chornyi, the owner of the Ukrainian-language science YouTube channel «А чому Всесвіт такий?» (@chomuvsesvit), to manage his own channel.

The tool runs locally on the owner's own computer as a command-line script and uses the YouTube API Services (YouTube Data API v3) to upload the owner's own episodes and Shorts, schedule their publication, set titles, descriptions, tags, video language and localizations, set thumbnails, organise the channel's own playlists, and post a comment from the channel under its own videos.

It is not offered to the public: there is no website application, no sign-up, no server and no other users. It accesses one YouTube channel — its owner's — after the owner signs in with Google OAuth 2.0.
